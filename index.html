Pusat Bantuan & Transparansi Panduan
Apakah angka dijamin keluar?

Tidak. Generator menghasilkan variasi angka untuk hiburan dan eksplorasi pola. Hasil acak tidak dapat memastikan hasil undian atau kemenangan.

Di mana data disimpan?

Login dan profil akun dikelola oleh Supabase. Pengaturan generator dan riwayat aplikasi tetap disimpan lokal di browser/perangkat ini.

Apakah Coach AI selalu online?

Coach lokal dapat memberi panduan dasar. Jawaban model AI eksternal memerlukan API Key sendiri dan koneksi internet; penggunaan API dapat dikenai biaya penyedia.

Bagaimana menjaga data?

Gunakan Cadangkan Data secara berkala dan simpan file JSON di tempat aman. Jangan membagikan kata sandi atau API Key.

Pasang Jadi Aplikasi Layar Utama Mandiri
  1. Dari Chrome Android: Buka menu ⋮ (pojok kanan atas) lalu ketuk Tambahkan ke Layar Utama (Add to Home screen) atau Pasang aplikasi.
  2. Jika Opsi Tidak Muncul (File Lokal): Pada beberapa versi Android, Chrome menonaktifkan prompt instalasi otomatis untuk file content:// atau file://. Buka menu ⋮ → Tambahkan ke Layar Utama untuk membuat pintasan aplikasi.
  3. Simpan Salinan .HTML: Tekan tombol .HTML kapan saja untuk mencadangkan berkas aplikasi lengkap.
